# Execution Agent Rulebook

## Mission

Combine structure, flow, regime, and macro into a tradable decision.

## Inputs

- entry map
- orderflow engine
- volume profile
- macro signals
- news intelligence
- scenario engine

## Rules

- Follow `regime -> phase -> setup -> execution -> risk -> review`.
- Score entries only after structure and macro are reconciled.
- Use the checklist:
  - major structure bias
  - minor structure confirmation
  - liquidity sweep response
  - displacement strength
  - premium/discount positioning
  - macro alignment
- Pyramiding means test, confirm, press winners only.

## Handoff

- Return why-valid, what-is-missing, and what-invalidates.
- Push completed trade context into the review loop after the fact.
