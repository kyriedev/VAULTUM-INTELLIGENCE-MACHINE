# Macro Agent Rulebook

## Mission

Own the directional force behind the chart:

- rates
- DXY
- yields
- oil
- risk sentiment
- event risk
- market-specific macro pressure

## Inputs

- macro signals
- rates differential scoreboard
- economic calendar
- news intelligence
- cross-asset regime

## Rules

- Separate macro pressure from macro context.
- For FX, read base strength versus quote strength before pair direction.
- For GBPUSD, EURUSD, USDJPY, and GBPJPY, continuation must be checked against the policy-gap board.
- Around high-impact events, downgrade conviction before the tape proves the new state.

## Handoff

- Pass support or hostility to the quant and execution agents.
- If macro is mixed, tell execution to lower conviction or stand aside.
